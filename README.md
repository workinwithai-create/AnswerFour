# AnswerFour

Four-bar live answer desk for bedroom producers stuck in loops.

Your loop has a call and nothing answers. AnswerFour writes four live bars: piano or nylon calls, trumpet or violin or bass answers on real FluidR3 samples so the section has conversation and can finish or hand off.

Live chairs only. Samples pinned to PreEight commit SHA. Not a lift. Not a tag. Not a key change. Distinct from TagFour, LiftTwo, PreEight, AfterHook, EndEight, LastHook.
